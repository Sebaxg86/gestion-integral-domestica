# Especificación de seguimiento del kilometraje

## 1. Objetivo

Mantener una bitácora confiable del uso de cada vehículo y utilizar la lectura
actual para anticipar mantenimientos definidos por kilometraje.

## 2. Alcance

- Registrar kilometraje y fecha desde el detalle del vehículo.
- Guardar una nota opcional para contextualizar la lectura.
- Conservar lecturas iniciales, manuales y generadas por otros flujos.
- Actualizar el kilometraje actual únicamente cuando la nueva lectura sea mayor.
- Mostrar las últimas veinte lecturas en orden cronológico inverso.
- Mostrar la distancia recorrida entre lecturas consecutivas.
- Permitir un recordatorio cada 30, 60 o 90 días.
- Reiniciar el periodo del aviso después de registrar una lectura.
- Mostrar mantenimientos cuando estén vencidos o falten 1,000 kilómetros o menos.

## 3. Reglas de negocio

- Cada lectura pertenece al mismo vehículo y familia.
- Solo la cuenta propietaria puede registrar o consultar lecturas.
- No se aceptan kilometrajes negativos, menores al actual ni fechas futuras.
- Dos lecturas idénticas del mismo día no crean registros duplicados.
- El historial es inmutable para evitar sobrescribir evidencia anterior.
- Archivar un vehículo cancela su recordatorio de actualización.
- El aviso periódico utiliza una fecha porque la aplicación no puede conocer el
  kilometraje real del vehículo sin una lectura proporcionada por la persona.

## 4. Flujo principal

1. La persona abre el detalle de un vehículo.
2. Captura el kilometraje mostrado en el tablero y confirma la fecha.
3. La aplicación actualiza el kilometraje actual y conserva la lectura.
4. Los mantenimientos se recalculan con la nueva distancia restante.
5. Si existe un aviso periódico, su siguiente fecha comienza desde esta lectura.
