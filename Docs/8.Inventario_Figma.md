visual del proyecto.

- Fills, strokes, bindings y efectos.

- Variables, colecciones y modos.
- Estilos locales.

## 10. Observaciones estructurales

Este apartado describe el estado actual; no implica que los puntos deban
corregirse automáticamente.

- La página Foundations está construida con posiciones absolutas y no usa Auto
  Layout.
- La paleta utiliza variables y cuenta con modos Light y Dark.
- Las variables conservan scope `ALL_SCOPES`.
- Los textos no usan variables de color ni estilos tipográficos locales.
- Solo existe una muestra tipográfica: Display 48/56 Bold.
- No existen escalas documentadas de spacing, radius, elevation o motion.
- No existen componentes, variants ni instancias.
- No existen frames móviles, desktop ni conexiones de prototipo.
- Las páginas Components, Mobile, Flows, Archive y Playground están preparadas,
  pero vacías.
- El frame tiene `clipsContent: true`; todo el contenido extraído queda dentro de
  sus límites de 1440 × 1200 px.
- Todos los nodos están visibles, desbloqueados y sin efectos.
