# Proyecto GID - Gestión Integral Doméstica 🚀

Aplicación PWA mobile-first para la gestión integral de viviendas, vehículos,
documentos, servicios, mantenimientos y responsabilidades familiares.

## 🌐 Demostración

> La aplicación se encuentra actualmente en desarrollo.

## ⚙️ Tecnologías utilizadas

- Next.js, React y TypeScript
- Progressive Web App (PWA)
- Tailwind CSS y diseño responsive mobile-first
- PostgreSQL, Supabase Auth, Storage y Row Level Security
- Vercel, GitHub Actions y pnpm workspaces

## 📚 Descripción

Este proyecto nació como una iniciativa personal para resolver una necesidad real de organización y gestión dentro de una familia.

Su objetivo es centralizar información doméstica importante y facilitar su consulta, seguimiento y actualización.

- ✅ Gestión de viviendas, vehículos, servicios y documentos familiares
- ✅ Registro de mantenimientos, vencimientos, pendientes y recordatorios
- ✅ Colaboración entre integrantes mediante usuarios, roles y permisos
